# TubeStack source snapshot

This directory preserves the source files, manifest, build configuration, README, and license from [TubeStack](https://github.com/TubeStack/TubeStack) at commit `ddb9ece4f9a189147d0aa5c4bc99bc4a7df46b0d` (version 0.2.1).

The current Chanopy code is maintained in the repository root, primarily in `dist/`. Building this historical snapshot with Vite produces TubeStack 0.2.1, not Chanopy 0.6.0.
